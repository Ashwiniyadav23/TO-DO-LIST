# Simple To-Do List Application 🚀

Ek **bilkul simple** to-do list app - **Koi library nahi, sirf JavaScript!**

## Features ✨
- ✅ **Add Task** - Naye tasks add karo
- ✅ **Edit Task** - Tasks ko edit karo
- ✅ **Complete Task** - Checkbox se mark karo
- ✅ **Delete Task** - Tasks delete karo
- ✅ **Clean Code** - Easy samajhne ke liye!

## Technologies 💻
### Frontend:
- **HTML** - Structure
- **CSS** - Styling
- **Vanilla JavaScript** - Logic (No React, No library!)

### Backend:
- **Node.js** - Server
- **Express** - REST API framework

## Kaise Chalayen? 🏃

1. **Dependencies install karo:**
```bash
npm install
```

2. **Server start karo:**
```bash
npm start
```

3. **Browser mein kholo:**
```
http://localhost:3000
```

## Code Samajhne Ke Liye 📚

### Backend (`server.js`):
5 simple APIs:
1. `GET /api/todos` - Sare todos lao
2. `POST /api/todos` - Naya todo banao
3. `PUT /api/todos/:id/toggle` - Complete/Incomplete karo
4. `PUT /api/todos/:id` - Edit karo
5. `DELETE /api/todos/:id` - Delete karo

### Frontend (`app.js`):
8 simple functions:
1. `loadTodos()` - Server se todos lao
2. `renderApp()` - Pura UI banao
3. `renderTodos()` - Todos ko HTML mein convert karo
4. `attachEventListeners()` - Buttons ko kaam karne do
5. `addTodo()` - Naya todo add karo
6. `toggleTodo()` - Complete/Incomplete karo
7. `editTodo()` - Todo edit karo
8. `deleteTodo()` - Todo delete karo
